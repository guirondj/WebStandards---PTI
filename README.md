# 🚀 Landing Page - Agência de Marketing Digital (PTI)

Este projeto foi desenvolvido como parte da **Produção Textual Individual (PTI)** da disciplina **Web Standards**. O objetivo foi criar uma Landing Page responsiva para um prestador de serviço local, utilizando tecnologias puras.

## 📋 Sobre o Projeto
A página foi construída com foco em conversão e usabilidade, simulando a contratação por uma empresa de pequeno porte. Seguindo o enunciado, a estrutura conta com **05 faixas** de conteúdo essenciais:

1.  **Hero Section:** Apresentação da agência com título de impacto e chamada para ação (CTA).
2.  **Serviços:** Listagem detalhada dos serviços oferecidos (Tráfego Pago, Social Media e Design).
3.  **Vantagens:** Seção dedicada aos benefícios e diferenciais competitivos da agência.
4.  **Sobre a Agência:** Informações institucionais para gerar autoridade e confiança.
5.  **Contato:** Formulário para captação de leads e futuras conversões.

## 🛠️ Tecnologias Utilizadas
O projeto respeita rigorosamente as restrições técnicas da Segunda Parte do enunciado:
* **HTML5:** Estrutura semântica conforme os padrões da web.
* **CSS3:** Estilização visual sem o uso de frameworks externos.
* **Flexbox:** Técnica utilizada para o alinhamento e distribuição do layout.
* **Design Responsivo:** Implementação de Media Queries para garantir o acesso via dispositivos móveis.

## 📐 Requisitos Atendidos
* Seleção de ramo de negócio de pequeno porte.
* Implementação de pelo menos 05 faixas de conteúdo.
* Uso exclusivo de HTML, CSS e FLEXBOX.
* Layout responsivo (Mobile-friendly).
* Publicação em plataforma de hospedagem gratuita.
