## 📋 Sobre o Projeto
[cite_start]A página foi construída com foco em conversão e usabilidade, simulando a contratação por uma empresa de pequeno porte[cite: 7]. Seguindo o enunciado, a estrutura conta com **05 faixas** de conteúdo essenciais:

1.  [cite_start]**Hero Section:** Apresentação da agência com título de impacto e chamada para ação (CTA)[cite: 7].
2.  [cite_start]**Serviços:** Listagem detalhada dos serviços oferecidos (Tráfego Pago, Social Media e Design)[cite: 7].
3.  [cite_start]**Vantagens:** Seção dedicada aos benefícios e diferenciais competitivos da agência[cite: 7].
4.  [cite_start]**Sobre a Agência:** Informações institucionais para gerar autoridade e confiança[cite: 7].
5.  [cite_start]**Contato:** Formulário para captação de leads e futuras conversões[cite: 7].

## 🛠️ Tecnologias Utilizadas
[cite_start]O projeto respeita rigorosamente as restrições técnicas da Segunda Parte do enunciado[cite: 7]:
* **HTML5:** Estrutura semântica conforme os padrões da web.
* **CSS3:** Estilização visual sem o uso de frameworks externos.
* [cite_start]**Flexbox:** Técnica utilizada para o alinhamento e distribuição do layout[cite: 7].
* [cite_start]**Design Responsivo:** Implementação de Media Queries para garantir o acesso via dispositivos móveis[cite: 7].
